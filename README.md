## 🚀 Featured Project : 01 🚀

### 🥇 Project Name: Payment Gateway Platform in KNAB 🥇

🎁**Teck Stack:** Java 17, Spring Boot (V-3.X.X), Microservices, Kafka, Redis, SAGA Pattern, Razor Pay

Design **scalable Payment-Gateway system** using **Java, Spring Boot, Kafka, Redis & Rest APIs** to support real-time money transfer & payment processing.
🔹Develop & integrated **Account, Transaction, Payment, Fraud Detection, Notification & API Gateway microservices**, following distributed microservice architecture with independent database management systems.
🔹Implemented **Saga Orchestration for distributed transactions, compensation, rollback, refund, and transaction consistency.**
🔹Implemented **event-driven asynchronous communication using Apache Kafka, enabling Fraud Detection, Notification, and Account services** to consume transaction events and process payment workflows independently.
🔹Implemented real-time **fraud detection using Redis caching with velocity, amount, and balance-percentage rules.**
🔹Implemented **API Gateway rate limiting using Spring Cloud Gateway and Redis, configuring a replenish rate of 10 requests/second with a burst capacity of 20 requests to control excessive requests** and mitigate automated/fraudulent transaction attempts.
🔹Containerized **Kafka, Zookeeper, and Redis using Docker Compose and performed End-To-End API testing with Postman.**





## 🚀 Featured Project : 02

### 🥇Project Name: JANE Healthcare Management System: - (Cloud Based Project) 🥇

🎁**Tech Stack:** Java 17, Spring Boot, Spring MVC, Spring Security, Hibernate, Microservices, REST APIs, Kafka, MySQL, AWS, API Gateway, Feign Client, Eureka, Resilience4j, Redis
🔹Developed a cloud-based healthcare management platform using **Java 17, Spring Boot, Spring MVC, and Microservices architecture** to support patient, doctor, and appointment management. 
🔹Designed and developed scalable RESTful APIs for patient registration, doctor management, appointment scheduling, consultation, and notification processing. 
🔹Implemented secure authentication and authorization using **Spring Security, JWT, Role-Based Access Control (RBAC) & Google Auth (Version: 2.0) to protect backend APIs.** 
🔹Implemented concurrency control and **transaction management (By using @transactional annotation)** to maintain data consistency during simultaneous appointment booking requests.  
🔹Implemented **Asynchronous, event-driven notification processing using Apache Kafka** for reliable email and messaging workflows. 
🔹Integrated **API Gateway, Eureka Service Discovery, and Feign Client to enable communication and service discovery** across distributed microservices. 
🔹Implemented **Resilience4j in Circuit Breaker to improve service reliability and handle failures between dependent microservices.** 
🔹Optimized MySQL database operations and backend API performance through **query optimization, JPA/Hibernate tuning, and Redis caching.**
🔹Implemented **Global exception handling using @ControllerAdvice & @ExceptionHandler** annotation handle specific exception with custom exceptions and standardized API responses for consistent error management. 
🔹Implemented password management and secure credential handling using **JWT configuration, environment-based properties, and SMTP email integration.** 
🔹Configured and deployed backend microservices on **AWS (EC2, S3, RDS, IAM, SNS, Cloud-Watch)** and maintained application configuration across different environments. 
🔹Implemented automated build, testing, and deployment pipelines using **Jenkins, CI/CD** following standard software development and deployment practices.
